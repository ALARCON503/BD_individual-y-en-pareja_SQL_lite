# README - Bases de Datos

## Descripción

Este proyecto contiene dos bases de datos relacionales diseñadas para gestionar información de diferentes entornos:

1. **Base de Datos Centro Escolar**
2. **Base de Datos Biblioteca**

Ambas bases de datos fueron desarrolladas utilizando un sistema gestor de bases de datos SQL y aplican principios de normalización para garantizar la integridad y consistencia de la información.

---

# Base de Datos: Centro Escolar

## Objetivo

Administrar la información académica de un centro escolar, permitiendo el registro y control de estudiantes, docentes, asignaturas, cursos y calificaciones.



# Base de Datos: Biblioteca

## Objetivo

Gestionar el préstamo y control de libros dentro de una biblioteca, incluyendo usuarios, préstamos y devoluciones.



# Instalación

1. Crear una nueva base de datos.
2. Ejecutar el script SQL correspondiente.
3. Verificar que todas las tablas se hayan creado correctamente.
4. Insertar los datos de prueba (si existen).
